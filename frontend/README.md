# `frontend/`

## Responsibility
The TypeScript + React (Vite) single-page app: expense entry form, CSV upload/dropzone, expense table, and summary/filter views.

## Contents
Empty as of Phase 0. Scaffolded with `npm create vite@latest frontend -- --template react-ts` in Phase 4.

## Why this approach
- **Vite**: fast dev server and build tooling, minimal config compared to CRA/webpack.
- **TypeScript**: strict typing over API responses and component props, catching integration errors with the backend contract at compile time.
- **React**: component model fits the planned UI (form, dropzone, table, cards) well, and has the largest ecosystem for a learner to find resources in.
